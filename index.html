🛰️ GitHub Follow Checker

See who isn't following you back

Enter a GitHub username to compare followers and following. Nothing is stored, every request goes straight from your browser to GitHub.

No login needed. You'll only be asked for an optional token if GitHub's public rate limit is hit.

GitHub's public rate limit was hit

Unauthenticated requests are capped at 60/hour. Adding a personal access token raises that to 5,000/hour, used only for this session, never stored.

A token with no scopes selected (classic) or a read-only fine-grained token is enough to check follow status. Create one on GitHub →
